# Optional Default workspace portrait backgrounds

Place the two generated WebP artwork files in this directory:

- `reading-nook.webp`
- `study-nook.webp`

The Default workspace includes a persistent selector in the portrait card, with Reading nook as its default. The Plain option restores the existing solid gradient. If the artwork files are not present, the gradient remains visible. No network requests or new avatar instances are needed. The artwork is not yet committed; the owner can extract the supplied asset ZIP into the repository root and commit the two files.
