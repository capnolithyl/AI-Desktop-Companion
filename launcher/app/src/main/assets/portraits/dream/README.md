# Dream artwork slots

Optional dedicated artwork (WebP, preferably landscape 4:3 with dark or transparent background and modest resolution):

- morning.webp: waking up / sunrise
- day.webp: quiet desk companion
- evening.webp: winding down
- night.webp: sleeping

Runtime falls back to bundled excited, smug, default and sleepy expressions respectively. Daytime automatic holiday mode takes precedence if festive artwork exists. No dedicated images are included in v0.16.0.
