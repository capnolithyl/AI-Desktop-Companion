# Mikan Desktop Companion

A free, local-first AI catgirl companion for Windows. Built with Tauri 2, React, TypeScript, and Ollama.

**v0.3.1:** Seamless frameless portrait with native shadow disabled, portrait dragging, dock-integrated controls, configurable colors/typography, Markdown messages, expandable log/settings, slash commands, Ollama model dropdowns and instant model switching, and Ollama response diagnostics.

See [SETUP.md](SETUP.md) for Windows installation, commands, and known limitations.

Roadmap: https://trello.com/b/bLO0mXJM/ai-desktop-companion
