# Mikan Desktop Companion

A free, local-first AI catgirl companion for Windows. Built with Tauri 2, React, TypeScript, and Ollama.

**v0.4.1:** Seamless frameless portrait with native shadow disabled, portrait dragging, dock-integrated controls, configurable colors/typography, Markdown messages, expandable log/settings, slash commands, Ollama model dropdowns and instant model switching, Ollama response diagnostics, five personality presets, randomizer, and expanded slash commands.

See [SETUP.md](SETUP.md) for Windows installation, commands, and known limitations.

Roadmap: https://trello.com/b/bLO0mXJM/ai-desktop-companion

**Local web search:** Mikan can query your own SearXNG instance without a paid API. See [SearXNG Windows setup](tools/searxng/README.md) to install and test it.
