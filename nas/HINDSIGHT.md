# Experimental Hindsight and Dream Mode

Defaults to existing SQLite. Historical import is explicit and available only on the Local retrieval backend (see below). Hindsight stores only explicitly enabled future owner excerpts, in the separate mikan-experimental-user bank, with the existing automatic user capture consent and privacy guard. Chat queries also leave Beholder via configured embedding/reranking services. Sensitive content should not be used in this experiment. SQLite manually curated memories remain editable; Hindsight documents/observations and derived summaries are managed separately, not silently overwritten through SQLite. Deleting a SQLite conversation does not yet erase a retained Hindsight document; this is an experimental limitation.

Use a private Docker network linking the running Mikan service and hindsight-test; never expose the Hindsight management/API ports publicly. Attach hindsight-test to the existing Mikan Compose network once (inspect the network name with docker inspect; use docker network connect with that exact name). Default internal address http://hindsight-test:8888; override via MIKAN_HINDSIGHT_URL and optional server-side MIKAN_HINDSIGHT_KEY. Keep the existing NAS container/volume; no Hindsight key or URL is supplied by the browser.

Settings → Memory engine & dreaming: test connection, choose Hindsight, enable capture and dreams separately. Direct recall uses bounded, typed/timestamped results and prefers consolidated observations. Missing/error falls back to SQLite; existing owner-editable facts, character canon and interests remain separate as compatibility context. No default Reflect call. New user writes are queued in SQLite and batched (up to four same-conversation excerpts), attempted after a minute of inactivity, bounded by a daily submission count. Ambiguous failed sends remain uncertain rather than retried blindly. Dream refresh uses native Hindsight mental models after 30 minutes idle, one operation at a time, only after successful new retains and bounded daily submissions. No automatic refresh trigger. No background work is promised to preempt an already in-flight provider call. These caps are not hard token limits; Hindsight's own workers share the NVIDIA quota independently.

Brain Lab can select Hindsight independently of live memory settings; creates a unique synthetic fixture bank per run and attempts cleanup. No production bank writes. Compare with same scenario/model/research mode, separately measure ingestion and consolidation latency; fixture dates and exact ranking may differ. This does not establish production accuracy.

Tests: node --experimental-strip-types --test nas/tests/hindsight.test.mjs. Run full NAS/TS build and live Beholder smoke tests before merging. Verify the installed Hindsight OpenAPI schema, auth, persistence and quota behavior; the API contract is based on upstream current docs, not verified against the installed image yet. Owner-reviewable Hindsight edits/deletes synchronization, model-specific provider budget ledger, hard token enforcement, character-specific dreaming and launcher status are future work.

Preview integration preserves the native model-led companion, mobile workspace, native Android JSON exports and provider diagnostics. Both automatic context and explicit recall_memory can use the selected engine. Hindsight Brain Lab runs do not populate SQLite fixture facts, so an answer cannot silently pass using the old fact engine. No automatic production data import. Hindsight's external provider calls still bypass the local inference ledger; background submissions require local NVIDIA headroom but are not centrally rate-limited.


## Local retrieval on Beholder (experimental)
The persistent sidecar uses the same pinned quantized BGE Small and FlashRank MiniLM L12 from the real NAS benchmark. Its HTTP API implements OpenAI-compatible embeddings (384 floats or base64) and Cohere-compatible reranking. Hindsight receives those two local endpoints using its existing slim image, so no PyTorch/AVX-dependent image is needed. BGE applies symmetric preprocessing because the generic embedding endpoint cannot infer which input is a query. Embeddings truncate at 192 tokens, rerank at 128; the 32/48 candidate ceilings are initial CPU tuning, not validated at scale. FlashRank weights are downloaded at build time from the pinned package's model location; weights are not independently checksum-pinned. No internet is required by the running sidecar (internal-only Docker network, no published ports), and it logs no text. There is no automatic cloud embedding fallback because vector spaces must not mix.

After the Preview image is installed:
- Extract the host installer from the running image: sudo docker exec nas-mikan-1 cat /app/nas/install-local-hindsight.sh > /tmp/mikan-local-hindsight.sh
- Run sudo sh /tmp/mikan-local-hindsight.sh install groq (default model openai/gpt-oss-120b; optional model argument, or explicitly choose cerebras/nvidia). Reuses only that provider's saved Mikan key; no key shown. The host script uses the existing installed Hindsight image ID, creates a separate 384-dimensional PostgreSQL volume and two new containers; never touches the legacy volume/container or Mikan SQLite. It refuses existing target names or volume rather than overwriting. On partial failure it leaves new containers/volume for inspection; do not delete anything blindly. Neither API is exposed on host ports. Hindsight joins the existing Mikan Compose network, and both new services share an internal retrieval-only network. Docker administrator can inspect provider credentials as with the old setup.
- Run sudo sh /tmp/mikan-local-hindsight.sh test to make one isolated synthetic retain/recall call; this uses the selected LLM and may hit free quota. It does not write owner facts. No automatic retry after ambiguous failure. Verify local sidecar counters with docker exec mikan-retrieval curl -fsS http://127.0.0.1:8090/health.
- Only after smoke success select Hindsight + Local retrieval in Memory engine & dreaming, test and save. Explicitly enable capture/dreams if desired. The backend picker is also used by Brain Lab. Legacy and local retain queues/config/dream operations are isolated in SQLite, and an inactive backend's worker is suspended. Existing source memories remain unchanged until and after any optional copy. A native operation already accepted by the old Hindsight server may still finish; its operation state is kept separately.
- Rollback: choose Original cloud retrieval or Existing SQLite in settings; stop the two new containers only if desired. Keep the volumes. No automatic migration, provider failover, or full cancellation fix. Cloudflare can replace retrieval in a future separate index, not as a silent embedding fallback. Groq is the default first LLM trial, not a proven free-tier solution; Hindsight's LLM requests are outside Mikan's usage ledger. The local worker checks current chat-provider headroom as a conservative admission hint; this does not track the actual independent LLM quota. End-to-end Hindsight compatibility needs live validation against the installed image; CI uses actual local retrieval models and mocked Hindsight API tests.

## Existing library import (Preview)
Save Local retrieval + Hindsight, select categories, preview, and approve. About You, Interests, About Mikan and existing summaries are converted deterministically to native transfer ZIP archives (manifest schema_version 1, one document/fact per record). Owner fact wording is preserved, structured interests and canon formatted without inference, summaries labeled as derived history. The source ID, record dates, metadata and original text are retained. Date saved/updated is not an event date. No invented entities. Up to 64 records / 128 KiB source payload per archive, one bank at a time, submitted privately over multipart to the installed OpenAPI-advertised document-transfer or bank merge endpoint, using conflict skip. No retain extraction or daily retain cap for curated archives; Hindsight may independently run cloud consolidation. Asynchronous operation IDs persist across restart; only mark complete with confirmed document and fact counts. No silent fallback if the installed version does not advertise support. Pause/discard queued work, inspect uncertain results, never automatically overwrite. Historical raw owner messages are optional, still use retain and the existing daily budget and privacy filter; no assistant messages. SQLite originals are untouched, edit/delete sync and character dreams remain future work. Test on a disposable synthetic bank before importing personal records.
